Self-contained GLB/glTF files are distributed in the public [Aetherium asset directory](https://github.com/danvanderboom/Aetherium/tree/main/samples/unity/Aphelion/Assets/ThirdParty/Quaternius).
Its [provenance record](https://github.com/danvanderboom/Aetherium/blob/main/samples/unity/Aphelion/ATTRIBUTIONS.md) maps these filenames to the original models.
Only the individual CC0 models are used, not that project's code.

Run `npm run assets:download` to install the external files into `client/public/models`, then build normally. The authored crew derivative is shipped locally and is preserved by the downloader.
To add only the monster to an existing installation, run `npm run assets:download -- leviathan`.
The monster is saved as `client/public/models/leviathan.glb` and loaded from there first.
Its online source is `https://gobkit.com/freebies/animal/Anglerfish.glb`, listed in the [publisher's manifest](https://gobkit.com/api/free); the public GitHub copy is a fallback.
Vite copies these files into the production build. Local files are preferred; if absent, the browser tries the public raw GitHub URLs.
If both requests fail, built-in geometry remains usable and the match continues.
This installation contains local model files. The creature and game scenes have been rendered in Chrome using software WebGL for visual checks.
The download command validates GLB headers and checks that glTF buffers/textures are embedded.

The existing station shell, collision geometry, and water remain code-generated; doors now slide instead of stretching.
The Leviathan is now an elongated abyssal predator: a tapered moving spine, ragged dorsal fins, a recessed mouth, multiple rows of irregular needle teeth, narrow eyes and a hinged jaw. These additions are authored locally in `client/src/leviathan-horror.js`.
The existing downloaded anglerfish contributes the cranial shell. Its colourful texture is replaced with dark skin, the exaggerated eye and lure bones are suppressed, and its proportions are refitted behind the new mouth.
The tactical update adds pursuit targeting between the station and escape pod. The tail carries a continuous travelling wave; the imported shell uses idle motion during swimming and attack motion during strikes, avoiding the original walking motion.
Current publisher files have separate named clips. The older GitHub copy uses a single baked timeline, handled using its documented frame segments so death frames never play during patrol.
If downloads fail, the same horror anatomy remains visible with its locally authored skull. Existing installations need no new download. Front and three-quarter attack poses were rendered and visually inspected in Chrome using software WebGL.
With Vite running, `/leviathan-preview.html` is a development-only creature study with front, side and attack views; it is not included in the production game build.
Character animation uses separately cloned skeletons and smoothly fades between idle, walk, and run based on server movement.
Downed crew retain the existing floor pose. Name tags retain department labels and colours.

The tactical update's cockpit, wreckage, beacon, maintenance route markers and cinematic staging are authored locally in code. Ending scenes reuse the creature and generated capsule geometry, with animated cameras and captions. No additional online assets or downloads are required. Horror cues and spatial effects remain generated audio; there is no recorded voice track.

The release-readiness pass adds original, deterministic industrial plate textures and water-normal data generated by `client/src/surfaces.js`, plus instanced station structure and reinforced wreckage. These require no external texture files. Rendering quality controls pixel density and ocean particle counts.

The exterior pass replaces the flat ocean floor and primitive scattered rocks with locally authored sediment terrain, sand/ripple normal maps, mottled rock surfaces, clustered outcrops, scree and branching sea fans in `client/src/ocean.js`. Cable runs connect the outside junctions to the hull. `client/src/wreckage.js` builds curved pressure-hull fragments with torn edges, actual punctures, bent supports, hanging cables and localized corrosion; station debris is partly buried in the terrain. The pod route uses the same wreckage language and sediment surfaces. These assets are generated locally and require no additional download.

The Leviathan now faces the displacement of its rendered position instead of assuming a single patrol direction. Initial facing respects the server's clockwise/counterclockwise choice, and retreat follows its outward movement. Its body wave travels from head to tail. These orientation and animation corrections leave the authoritative attack rules unchanged.

The MANTA rescue craft in `client/src/escape-craft.js` is an original code-authored model: shaped pressure hull, ceramic armor, framed canopy, rescue livery, hatch, lifting bridle, landing skids and guarded animated propellers. The transfer and compact maintenance variants replace the generic pod models at the station and the capsule-with-circle visual in the epilogues. Static details merge by material to keep the mesh count low. Hull markings use a locally generated canvas texture; no external model, texture download or additional asset license is required. Station versions fit within the existing interaction and collision footprints.

## Original audio

The 32 WAV files in `client/public/audio` are original, locally authored procedural sound designs, rendered offline by `scripts/sound-design.mjs` and `scripts/render-audio.mjs`. They combine filtered noise, resonant steel modes, pressure transients and subtle mechanical harmonics. They do not contain third-party recordings, music or voice samples. No audio download, external audio service or additional attribution is required. Rebuild them with `npm.cmd run audio:render`.

These assets replace the former runtime oscillator beeps and melodic completion cues. They include station/ocean/surface beds, propulsion, water rush, hull/creature sounds, hydraulic equipment, alerts and movement sounds. The shipped bank is approximately 4.5 MiB of mono 24 kHz PCM WAV. A shared Web Audio mixer adds spatial positioning, environmental filtering, bounded voices, warning ducking and compression. `test/artifacts/sound-preview.wav` is a local audition reel assembled from the same samples.

## Original station identity detail

`client/src/station-detail.js` authors the survey recorder, power bus, storage, treatment cot, ceiling services, route markings, signage, incident records, strike scars and particle effects locally. Its signs and cracks use original canvas textures, and its soft light/particle falloff uses a small generated data texture. The ZIP reference informed room composition and atmosphere; its code, assets, fonts and effects were not imported. The furniture occupies existing collision footprints and the static parts merge by finish. No additional asset downloads or licenses are required.

The sealed technician in `client/public/models/Animated/nereid-diver.gltf` is rebuilt with `node scripts/prepare-diver.mjs` from the installed CC0 rig. It removes the animal head and carried weapon, replaces the cartoon atlas with muted vertex-coloured workwear, and adds an original helmet attached to the animated head bone. Original animation clips are retained. There is no online fallback to the animal character. Department badges are drawn locally. The riveted, grated, diamond-plate, tile and hazard surfaces are original deterministic canvas textures. `client/src/power-unit.js` adds an original four-batch power distribution assembly inside the existing panel footprint, without additional lights or shadow passes.

The station circulation and extraction expansion adds original pressure-vessel roofs and a severed lift assembly (`station-exterior.js`), eroded escarpments and a damaged survey receiver (`ocean.js`), and a five-batch curving wreck corridor (`route-scenery.js`). The route centerline and collapse gates come from `shared/escape-route.js`, shared with authoritative finale rules. `rescue-sequence.js` stages the existing MANTA, recovery carrier and Asterion through a continuous ascent, buoy, surface sling and deck recovery. The sling, hook, buoy, water normals, bubbles and gradient sky are generated locally. No film assets, external textures or additional licensed content are used.

The limited equipment in `client/src/equipment-view.js` uses original code-authored cylinders and emissive materials. Its text symbols use the existing system font. Equipment cues reuse the original local audio bank with explicit captions; no external models, recordings, paid services or API keys were added.

Department gear uses the same locally authored audio bank, with distinct positional activation cues and captions for welding, active scanning, air release and the EVA home marker. The fourth hotbar slot and textual bearing readouts use system fonts and CSS. No imported tool models, third-party sounds, additional lights or paid services were added.

Supply lockers reuse the existing Engineering tool cabinet and Medical storage. `client/src/locker-view.js` adds two original mounted canvas labels, redrawn only when stock/stage changes; it adds no lights or colliders. Checkout uses an original local mechanical cue with a distinct caption. No downloads, external textures, services or licenses are required.

`client/src/resource-view.js` creates original moored exterior supply vessels from cylinders, protective bands, handles, reflective strips, cables and anchors. Five canisters share six instanced batches and have no additional lights, shadow passes or downloaded textures. Their anchors use the existing seabed height function. Recovery reuses an original local mechanical cue with its own caption. No external models, recordings, paid services or API keys were added.

`client/src/exploration-view.js` adds original eroded basalt formations, deep-water fans, the ribbed survey wreck, seabed-anchored wayposts and safety-net boundary. It reuses local industrial/rock maps and draws mounted route signs into one original canvas atlas. Geometry batches by six materials plus the atlas, with no added lights or shadows. Shared footprints and route definitions are in `shared/layout.js`; no external models, image downloads, paid services or API keys were added.


Wreck salvage regulator: original procedural geometry using the existing instanced supply renderer, with a larger brass body, end caps, handle and cradle tether. No external assets, downloads, additional lights or paid services. Recovery/installation reuse the original local sound bank with existing captions and text confirmations.

Evidence terminals and twelve NEREID-9 record texts are original procedural/content assets. Terminals share two instanced draws, use no lights/shadows, and contain no downloaded art or third-party text.

Crafting and hazard additions: alloy uses the original moored-supply geometry; local circuit plates, six-legged skitters, sensor mines and the Warden silhouette are original procedural Three.js geometry. Bounded shared meshes add no lights or shadow casters. New tool/impact cues reuse the authored local sound bank with specific captions; no downloaded or paid assets were added.
