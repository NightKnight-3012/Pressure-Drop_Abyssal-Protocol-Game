# Development priorities

The browser game keeps its existing Three.js client, shared collision layout, pure server rules and Socket.IO lifecycle. No rewrite or paid service is needed for this roadmap.

| Suggestion | Current assessment |
| --- | --- |
| Grim visual style, wrist computer, readable labels, quality options, directional audio | Already implemented. Keep screenshot and performance checks as these features grow. |
| Limited tools and a hotbar | First phase implemented: one flare, acoustic lure and breach repair kit per player, authoritative consumption, cooldowns and reconnect state. |
| Mission complications | First real event implemented: obstructed pump, optional noisy maintenance, measurable drainage reward. More event types should wait for playtesting this one. |
| Leviathan encounters beyond attacks | Listening pass implemented using its actual position and existing sound-driven rules. More authored encounters can follow; each needs a fair cue and counter. |
| Post-match timeline | Implemented from actual server events. It records significant actions rather than invented heroic moments. |
| Department signature gear | Implemented in slot 4: portable Engineering welder (fast/noisy patches), Command scanner (brief last-known contact report), Medical oxygen canister, and EVA return marker. Server validates roles, charges, range, state and shared cooldowns. No new required jobs, creatures or lights. |
| Lockers and workbench | Finite Engineering/Medical lockers implemented: shared stock scales with crew tiers, proximity/front-side and slot checks are authoritative, concurrent last-unit requests grant once, and reconnect cannot refill stores. Shared items only. Seeded finite alloy caches and validated Engineering fabrication now supply common tools and department counters. |
| Bigger ocean, biomes, depth and outside pickups | 120m survey area implemented: flats, vent garden, survey wreck, basalt cleft, shared obstacles, marked routes, visible net boundary, zone visibility, expanded Command map and early return-air warnings. Seeded supplies include a near-hull kit and an optional landmark. Required cable work stays near the hull. Divers now have server-integrated depth, shared-floor limits and pressure-based air consumption. SKIFF-2 remains at survey level. |
| Wreck salvage | Implemented: one regulator at the wreck, four-slot cargo, noisy timed recovery/installation and +20 pump-flow points. Optional at every crew size, loss recovery, authoritative snapshots and tests. Playtest its risk/reward before expanding salvage further. |
| Two-seat submersible | Implemented: SKIFF-2 pilot/operator seats, validated movement, swept collision, hull/air, charges, repair, reconnect takeover and timed Medical docking. Horizontal survey-depth vehicle; no autopilot/combat gun. |
| Skitters and flooded electrical hazards | Implemented: breach-fed skitters, live-water faults and local circuit isolation, with warnings and tested counters. |
| Mines and a light-hunting Warden | Implemented as limited encounters: anchored mines on optional detours, one late light-hunting Warden, and host-selected difficulty. All have explicit warnings and counters; they pause during the established finale. |
| Story logs and case file | Implemented: twelve original NEREID-9 records, five seeded terminals per run, shared validated collection, local case file, event radio and four report variants. |
| Tutorial and controls | Implemented: solo simulator using real movement, repairs, tools, outside work and pod docking, plus persisted movement/interaction bindings, invert and FOV. Practice is separate from scored expeditions. Controller support remains a later extension. |
| Public matchmaking, Docker, stats and moderation | Implemented: server-local public browser/Quick Match, private-by-default rooms, anonymous identities, SQLite personal stats/public boards, local mute, reports, operator bans, process limits, health and graceful shutdown. Container files and deployment docs included; Docker unavailable for a container build here. |

Each phase must include tests for its new rules, the full regression suite, a client check, relevant screenshots, README updates, and `npm run balance`. Software-rendered screenshots verify appearance and overlap; they do not establish 60 fps on players' hardware.

Current limits: locker and exterior pickups replenish shared items only; finite fabrication exists, but no trading/dropping, diver depth is limited to the survey envelope, the sub stays horizontal, skitters do not yet attack machinery, anchored mines do not drift, Warden stays out of the pod finale, anonymous identities are not verified accounts; no global matchmaking service. The Leviathan remains station-oriented. Tool models are original geometry; equipment sounds reuse the authored local bank with captions. Camera-relative gloved hands and tools now animate actual repairs/welding and simple other holds; panel contact IK, articulated finger animation and new tool audio loops remain outside this first version. Flares/lures deploy at the player's authoritative position rather than being thrown; navigation and the return-air estimate are not obstacle-aware autopilot.
